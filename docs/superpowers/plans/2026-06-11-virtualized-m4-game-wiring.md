- **THE RECONCILIATION (pinned — how variation + state visuals survive the library/instance split):**
  1. **Exact, into the instance transform:** lot yaw + `yaw_jitter` + `frontage_correction_yaw` → `AtomInstance.rotation` (yaw-only quat); lot center + rotated `local_offset` + `setback_jitter` → `AtomInstance.position`. Source of truth: call the EXISTING `InstanceFrame::for_payload` and read `frame.pos` / `frame.rot` — one frame, two consumers, no re-derivation.
  2. **Exact, into baked library variants (game-side, cook-once):** `mirror_x` (a det = −1 map — cannot ride a quat) and the facade/trim HSV jitter (per-atom, CHANNEL-conditional — cannot ride any per-instance uniform) are baked into **8 deterministic variants per asset**: 2 mirror states × 4 jitter buckets. Variant atoms: position `[x·m, y, z]` (m = ±1; cooked atoms are `Quat::IDENTITY`, extents symmetric — mirroring is a position-x negation), color `variation_channel_rgb(channel, atom.color, &bucket_rep)` with the bucket representative jitters pinned as the quartile midpoints of the legacy uniform ranges: hue `{−0.015, −0.005, +0.005, +0.015}`, sat `{−0.06, −0.02, +0.02, +0.06}`, val `{−0.045, −0.015, +0.015, +0.045}`. Variant index per instance: `mirror = variation_bits(seed, 1) & 1` (the EXACT legacy mirror bit — the 50 % split is preserved), `bucket = (variation_bits(seed, 5) >> 1) & 3` (derived from the legacy hue-jitter channel's bits). Library cost: starter set 5 assets × 8 ≈ 201k atoms ≈ 13 MB GPU — trivially resident.
  3. **Per-instance, via the ADDITIVE engine change (Task 1):** `InstanceVisualParams` (48 B POD, identity-defaulted buffer in `ExpandDrawsPass`) carries `scale: [f32;3]` = `variation.scale ⊙ [1, visual.y_scale, 1]` (anti-CGA ⊗ construction height — applied to atom-local position AND extents componentwise), `opacity_scale: f32` (1.0 — reserved), `spectral_filter: [f32;8]` = the pair-averaged bins of `rgb_to_spectral(visual.tint)` for non-identity state tints, else exact `1.0`s. Construction grey / abandoned grey become a per-band spectral filter — a physically sensible multiply that approximates the legacy RGB multiply (both tints are near-neutral; deviation is recorded, the screenshot pair is the proof).
  4. **Accepted drift (recorded, not hidden):** (a) extents under anti-CGA scale: legacy uses the uniform `cbrt` factor, the instanced path scales extents componentwise — ≤ 0.8 % difference, below perception; (b) `y_scale` scales atom-local Y before the instance quat — exact under civitas's yaw-only rotations, documented as the validity domain; (c) socket consumers (door path, chimney, wisps) and vegetation splats do NOT ride the instanced path in M4 — they are per-instance unique geometry; recorded as the named follow-up (`m5-decorations`), the before/after pair shows the difference honestly; (d) the hybrid MESH near-field path is not used in instanced mode (atoms only) — also visible in the pair, also recorded.
  5. **State visuals are LIVE:** `visual_for` changes (construction progress ticks, abandonment) only rewrite the 48 B instance + 48 B visuals entries (a `set_instances` + `set_instance_visuals` call on world tick) — never the library, never the renderer.
