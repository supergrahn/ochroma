**Goal:** Land the first deep-sim milestone: persistent households anchored to the real houses they occupy (via the `BuildingRegistry`), a per-lot `LandValueField` recomputed every tick from amenities/roads/industry, the multiplicative land factor in `BuildingInstance::value()` (so the property-tax base feels place), and the observable surface — the `v` land-value overlay, the inspector `Land value` line, and the info-window `Land value avg · top` line.

**Architecture:** A new tick step **1d** runs after the registry tick (1c) and before demographics (2): **1d.1** `HouseholdRegistry::reconcile` resolves every residence to its lot center through the instance registry (seeded/unlinked residences keep the legacy `[id×10, 0]` strip), then **1d.2** `LandValueField::recompute` scores every lot (developed and vacant) from BASE + park/school/health/safety/care terms + road-class frontage bonus − industry falloff, and the result is written onto each instance (`apply_land_values`) so `value()` carries `× (0.9 + 0.2·lv)`. `Demographics::build` gains a position-resolver parameter; `CivitasGame::tick` passes the registry's resolver so care radii and water barriers measure to real houses — **the distance math itself is untouched** (the SDF Group D geodesic field replaces it separately). All state is recomputed by the action-log replay: no `SAVE_VERSION` bump, no new `AuthoredAction`s.
**Design Document:** `docs/superpowers/specs/2026-06-10-deep-simulation-design.md` (M1 = §2-M1, §4.1, §4.2, §4.9 M1 rows, §5, §6; §4.7's baseline — `development_demand()` / `demand_for_supply()` — is already in the code and is NOT touched by M1)
**Tech Stack:** Rust (workspace toolchain as-is), game repo `~/Ochroma/projects/civitas_care` (glam 0.29, winit, ab_glyph in hud). Engine crates **read-only**.

```rust
/// Persistent identity for one residence's occupants across ticks.
#[derive(Debug, Clone, PartialEq)]
pub struct HouseholdRecord {
    pub residence: u32,          // engine building id, or synthetic 100_000+ seed id
    pub formed_tick: u64,
    pub dissolved_tick: Option<u64>,
    pub anchor: [f32; 2],        // real lot center via instance link, else [id*10, 0]
    pub workers: u32,
    pub dependents: u32,
}

#[derive(Debug, Clone, Default, PartialEq)]
pub struct HouseholdRegistry {
    records: Vec<HouseholdRecord>,   // creation order — stable
    by_residence: Vec<(u32, u32)>,   // sorted (residence, records index) — binary search, no HashMap
}
```

`impl HouseholdRegistry`: `pub fn reconcile(&mut self, citizens: &[vox_sim::citizen::Citizen], instances: &crate::instance::BuildingRegistry, lots: &[crate::lot::layout::LotPlan], now_tick: u64)` — (a) build a sorted `Vec<(engine_building, plan_idx, lot_idx)>` from `instances.iter()`; (b) collect `(residence, workers, dependents)` per residence from citizens (a `Vec` sorted by residence id — count `dependent_kind` via lifecycle exactly like `care::demographics::dependent_kind`: `Worker` ⇒ worker, anything else ⇒ dependent); (c) visit residences in **sorted id order**: create a record on first sight (`formed_tick: now_tick`), refresh `anchor`/`workers`/`dependents` every tick, clear `dissolved_tick` if re-occupied; (d) every existing record whose residence is absent this tick and not yet dissolved gets `dissolved_tick = Some(now_tick)` (counts zeroed); (e) rebuild `by_residence` sorted.
