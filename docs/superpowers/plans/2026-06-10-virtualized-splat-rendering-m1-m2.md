# Virtualized Splat Rendering — M1 (Instanced Selector Oracle) + M2 (GPU Expand) Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use **superpowers:subagent-driven-development** (recommended) or **superpowers:executing-plans** to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Land the engine half of virtualized city rendering: a CPU instance-aware budget selector (`AssetAtomLibrary` + `InstancedSelector`, proven against the shipped `AtomBudgetSelector` oracle) and a GPU expand pass (`ExpandDrawsPass`) that writes the selected, instance-transformed atoms into the tiled chain's persistent buffers on the shared `GpuContext` with zero renderer reconstruction — plus the `scale_trial --instanced` harness that PRINTS the real splat counts and frame milliseconds on the 780M (the 60 fps gate itself is M3, out of scope here).
**Done When:** On the AMD 780M (RADV), all three of:
1. `cd ~/src/ochroma && cargo test -p vox_render --lib instanced_selector -- --nocapture` prints `[instanced] 10000 instances x 5000-atom asset = 50000000 virtual atoms | budget=1000000 selected=<S> visible_instances=<V> select_ms=<T>` with `900000 ≤ S ≤ 1000000` and real nonzero `V`/`T`, plus `[instanced] near_atoms=<n> far_atoms=<f>` with `n ≥ 50·f`, `1 ≤ f ≤ 64`.
2. `cargo test -p vox_render --lib expand_ -- --nocapture` prints `[expand] atoms=<≥100000> max_abs_dev=<d>` with `d < 1e-5`, and `[expand] frame1 non_black=<a> frame2 non_black=<b> sentinel=intact constructions=1` with `a > 0`, `b > 0`, from two different cameras over ONE renderer built once via `new_with_capacity`.
3. `cargo run --release -p vox_app --bin scale_trial -- --instanced --buildings 10000` prints `[scale_trial] instanced: 10000 buildings | library_atoms=<L> virtual_atoms=<V≈50M> | budget=<B> selected=<S≤B> | select+expand+render p50=<X> ms p99=<Y> ms @ 1280x720` with every placeholder a real measured number and `S ≥ 0.9·B` — the `X ≤ 16.6` gate is **M3's Done When, not asserted here**; this plan only guarantees the line exists and the numbers are real.

**Architecture:** Two-level budget cut mirroring the city instead of a Nanite DAG: an instance pass (frustum + distance classifies each placement as culled / far-imposter / near-cluster-granular) feeds the proven `atom_budget` host heap walk extended with two asset-level imposter LODs (I0 ≤ 64 atoms, I1 = 1). The selection (`Vec<ClusterDraw>`, prefix-summed offsets) drives a GPU compute expand — one thread per selected atom — that transforms asset-local library atoms into `GpuSplatFull` + transform pairs written directly into `TiledSplatRenderer`'s persistent `splat_buf`/`transform_buf` (the `GiCombinePass`-writes-into-`splat_buf` contract). The frozen four-pass tiled chain is untouched; capacity is budget-derived (`ENTRY_HEADROOM = 16`), not worst-case.
**Design Document:** `docs/superpowers/specs/2026-06-10-virtualized-splat-rendering-design.md`
**Tech Stack:** Rust (workspace, edition 2024), wgpu 24, glam 0.29, bytemuck 1, half 2 (vox_render). `vox_app` has **no bytemuck dep** — harness readbacks go through `TiledFrame::resolve_to_srgb` or manual `f32::from_le_bytes` (existing scale_trial pattern).
**Build:** `cargo build` / `cargo test -p vox_render --lib`. GPU tests are plain wgpu — **no SPECTRA env, no Slang, no `build-spectra-native.sh`** (those exist only for `spectra-native` feature tests, which this plan never touches). GPU tests skip gracefully (printed skip line, exit green) on boxes without a hardware adapter, per the house `try_gpu` pattern.

The shader (`tile_assign.wgsl`) writes `tile_keys_hi[atomicAdd(&tile_count,1)]` **without a capacity guard**; safety under budget-derived sizing comes from wgpu/naga default bounds-checked storage access (OOB writes discarded) plus the existing host clamp in `render()` (`v.min(self.max_tile_entries)`). Overflow count = `v.saturating_sub(max_tile_entries)` — expose it (Task 3).

  - `render()` reads `self.splat_count` each frame to build `AssignCameraUniform` and size the dispatch — `set_active_splat_count` is therefore **just a clamped field write** (the uniform is rewritten every frame anyway); no extra GPU work.

- **Determinism keys:** instance pass output ordered ascending instance index; near-cluster work units ordered (instance index, cluster id); heap tie-breaks by `work_idx` exactly as the oracle's `DemoteEntry`/`PromoteEntry` `Ord` impls; shed order `(score, instance, cluster)` ascending; draw emission ascending (instance index, unit); `atom_offset` = running prefix sum in emission order → disjoint GPU write slots → deterministic buffer contents.
- **Expand math (pin, for the oracle test):** `pos' = instance_quat * atom_pos + instance_pos` (`glam::Quat::mul_vec3`), `quat' = instance_quat * atom_quat` (`mul_quat`, instance applied AFTER atom), atom quat from `decoded_rotation()`; `opacity' = (opacity as f32 / 255.0) * opacity_scale`; spectral = the 8 pair-averaged bins, stored f16 in the packed library atom and unpacked to f32 in-shader — the CPU oracle compares positions/quats at `< 1e-5` abs and spectral against the f16-round-tripped value. Packed library atom (64 B, asset-local): vec4 `pos.xyz + opacity_f32(0..1)`, vec4 `scale.xyz + 0`, vec4 `quat xyzw`, 4×u32 `8 × f16 bins` (this refines the design's `opacity_u8x4` sketch — same size, simpler exactness).

Near = `< 150 m` → per-cluster work units, each **individually frustum-tested** on its transformed cluster sphere (required for oracle equality and budget honesty), distance LOD via `select_lod_level` on the transformed cluster center. Imposter and cluster units compete under the one score formula.
